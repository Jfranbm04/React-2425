# Proyecto de Pojemon con uso de React Router V7

Se pretende realizar un proyecto que utilice las siguientes tecnologías:

> - React Router Dom en su version 7
> - Contextos globales
> - Librería Sonner para notificaciones
> - Estilado con Tailwind CSS

El Scaffolding que se va a utilizar es el siguiente:

```text
src/
├─ components/
│  └─ NavBar.jsx
├─ context/
│  └─ PokemonContext.jsx
├─ layout/
│  └─ RootLayout.jsx
├─ pages/
│  ├─ Home.jsx
│  ├─ Search.jsx
│  ├─ PokemonDetail.jsx
│  └─ Favorites.jsx
├─ routes/
│  ├─ Router.jsx
│  └─ paths.js
├─ App.jsx
└─ main.jsx
```
